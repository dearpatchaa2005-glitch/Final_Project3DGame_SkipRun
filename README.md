# Skip Run (มิวต้องไปให้ได้) — เกม 3D Endless Runner (Godot)

วิชา Computer Game Development CP410844 
เนื้อเรื่อง: น้องสาวของ **มิว** ป่วยกะทันหันที่โรงเรียนอนุบาล แต่ขอครูออกไปรับไม่ได้เพราะวันสอบ มิวจึงข้ามรั้วโรงเรียนหนีออกไป แต่ถูก **ครูวินัย** ครูฝ่ายปกครองเห็นเข้า (โดยไม่รู้เหตุผล) จึงต้องวิ่งหนีผ่านเมือง หลบสิ่งกีดขวาง และเก็บ "เหรียญดาวความดี" เพื่อชดเชยคะแนนความประพฤติ

## วิธีเปิดโปรเจกต์
1. ติดตั้ง Godot 4.x (ทดสอบกับ 4.6, เปิดด้วย 4.7 ได้)
2. เปิด Godot → **Import** → เลือกไฟล์ `project.godot`
3. รอให้ Godot import ไฟล์ FBX ตัวละครครั้งแรก (ใช้เวลาสักครู่)
4. กด **F5** เพื่อเล่น (ฉากหลักคือ `scenes/main.tscn`)

ใช้ renderer แบบ GL Compatibility จึงรันได้บนเครื่องทั่วไป

## ลำดับในเกม
หน้าหลัก (ชื่อเกม ช่องกรอกชื่อผู้เล่น เริ่มเกม สถิติของฉัน เครดิต) → เนื้อเรื่อง 6 หน้า เล่าเป็นฉากจริงในเกม (น้องสาวป่วยกะทันหัน → ขอครูไม่ได้ → วิ่งกระโดดข้ามกำแพง → ครูวินัยเห็นที่ประตู → ไล่ล่า → วิธีเล่น) → นับถอยหลัง → วิ่ง → จบเกม (สรุปดาว ระยะทาง คะแนน คะแนนสูงสุด) → เล่นอีกครั้ง / ดูเนื้อเรื่องอีกครั้ง / กลับหน้าหลัก

## สถิติผู้เล่น
ทุกรอบที่เล่นจะถูกบันทึกอัตโนมัติพร้อมชื่อผู้เล่น (ระยะทาง ดาว คะแนน วันที่-เวลา) ดูได้ที่ปุ่ม **สถิติของฉัน** ในหน้าหลัก (สรุปรอบที่เล่น คะแนนสูงสุด ระยะไกลสุด ดาวสะสม รายการ 10 รอบล่าสุด และอันดับผู้เล่น) ไฟล์เก็บที่ `user://skip_run_records.json` (Windows: `%APPDATA%\Godot\app_userdata\Skip Run\`) พิมพ์ชื่อต่างกันจะแยกสถิติกัน

## กติกา
- วิ่งอัตโนมัติ ความเร็วเพิ่มขึ้นตามระยะทาง มี 3 เลน
- ชนรถ รถบัส หรือคนเดินถนน = จบเกมทันที
- ครูวินัยตามหลังอยู่ ระยะห่างค่อย ๆ ลดลง เก็บดาวเพื่อผลักให้ห่างขึ้น ถ้าถูกจับ = จบเกม
- คะแนน = ดาว × 10 + ระยะทาง (เมตร)

```
          obstacle.gd, star_coin.gd, power_up.gd (ไอเท็ม),
          road_path.gd (เส้นทางถนนตรง/โค้ง), track.gd (เมืองไม่รู้จบ),
          editor_preview.gd (ตัวอย่างฉากที่เห็นใน Editor),
          props.gd (โมเดลโลว์โพลีจากโค้ด), character_model.gd,
          game_ui.gd (UI + เนื้อเรื่อง), menu_ui.gd (หน้าหลัก/สถิติ/เครดิต),
          records.gd (บันทึกสถิติ), audio.gd (autoload)
characters/ (FBX Mixamo), sounds/, fonts/ (Sarabun, Kanit)
assets/city/  (โมเดล Kenney .glb แยกเป็นชุด)
tools/    สคริปต์ช่วยสร้างฉาก/ทดสอบ (ไม่จำเป็นต่อการเล่น)
```

## แนวคิดการออกแบบ (บรรยากาศตลก เบาสมอง)
- **เรื่องใกล้ตัว เข้าถึงง่าย:** ทุกคนเคยอยู่ในสถานการณ์ที่ต้องรีบทำอะไรสักอย่างโดยไม่มีเวลาขออนุญาตใคร แล้วลุ้นตัวโก่งว่าจะโดนจับได้ไหม — มิวก็แค่คนธรรมดาที่เจอเรื่องฉุกเฉินและตัดสินใจผิดจังหวะ ไม่ใช่เด็กเกเร จึงเอาใจช่วยได้เต็มที่
- โทนภาพสดใส สีจัดจ้านแบบเมืองยามเช้า (ท้องฟ้าสีพีช ตึกสีลูกกวาด) ให้ความรู้สึกสนุกมากกว่าตึงเครียด แม้สถานการณ์จะเร่งรีบ
- รายละเอียดตลก ๆ ระหว่างทางที่ทำให้ฉากหนีดูเบาลง: รถเข็นแม่ค้า (หมูปิ้ง ปาท่องโก๋ ฯลฯ), คนงีบบนม้านั่ง (Zzz), แมวจร, ป้ายร้านชื่อขำ ๆ บนตึก (เช่น "ตัดผมทรงนักเรียน"), รถเมล์สาย 8 ที่แน่นเอี๊ยดหน้าผู้โดยสารแนบกระจก, คนเดินถนนพูดบ่น ("ง่วงจัง...", "อ้าว มิว!")
- ครูวินัยวิ่งไล่ตามหลังพร้อมตะโกนบ่นเป็นระยะ ยิ่งใกล้ยิ่งถี่ สร้างความตื่นเต้นแบบขำ ๆ ไม่รุนแรง เพราะครูไม่รู้เหตุผลที่แท้จริง ผู้เล่นจึงรู้สึกเหมือนอยู่ในสถานการณ์เข้าใจผิดที่พลิกได้ทุกเมื่อ
- เหรียญดาวความดีและใบลาป่วยล้อเลียนระบบคะแนนความประพฤติของโรงเรียน ให้ผู้เล่นรู้สึกว่ากำลัง "ชดเชยความผิด" ด้วยการเก็บความดีระหว่างหนี ทั้งที่ความจริงมิวไม่ได้ทำอะไรผิด แค่ไม่มีใบลาในมือ
- ข้อความตอนจบเกมสุ่มมุกตามสาเหตุที่แพ้ ให้แพ้แล้วยังขำได้ ไม่รู้สึกว่าเกมดุหรือกดดันเกินไป
- ควบคุมง่าย แค่ซ้าย-ขวา/กระโดด/ก้ม แต่ต้องตัดสินใจเร็วตามจังหวะสิ่งกีดขวางที่เข้ามา


## ฉากตัวอย่างใน Editor
เปิด `scenes/main.tscn` ใน Godot จะเห็นถนนโค้ง ตึก รถ รถเมล์ คนเดิน สิ่งกีดขวาง ดาว และไอเท็มวางเต็มใน 3D viewport (อยู่ใต้โหนด `EditorPreview` ดูชื่อชิ้นส่วนได้ใน Scene tree) ตอนกดเล่นเกมโหนดนี้จะลบตัวเอง เพราะเกมสร้างถนนสุ่มไม่รู้จบด้วยโค้ด ซ่อนใน Editor ได้โดยปิดตา Visible ของ `EditorPreview`

## ไอเท็ม (โผล่เป็นระยะบนถนน)
- **ใบลาป่วย** — กันการชนได้ 1 ครั้ง
- **แม่เหล็กดาว** — ดูดดาวรอบตัวเข้าหาเอง 8 วินาที
- **รองเท้าวิ่ง** — พุ่งเร็วขึ้นและทะลุสิ่งกีดขวางได้ 3.5 วินาที พร้อมดันครูให้ห่าง



## โมเดล Kenney 
อยู่ในโฟลเดอร์ `assets/city/` (แต่ละชุดมีโฟลเดอร์ Textures ของตัวเอง ห้ามลบ)
| โฟลเดอร์ | ชุดของ Kenney | ใช้ทำอะไร |
|---|---|---|
| `buildings/commercial` | City Kit (Commercial) | ตึกร้านค้า / ตึกสูงสองข้างทาง |
| `buildings/suburban` | City Kit (Suburban) | บ้านเรือนริมทาง |
| `buildings/` | Starter Kit City Builder | ตึกเล็ก / โรงรถ |
| `vehicles/carkit` | Car Kit | รถเก๋ง แท็กซี่ SUV รถส่งของ ตำรวจ รถพยาบาล รถขยะ |
| `vehicles/` | Starter Kit Racing | รถบรรทุกสี ๆ |
| `props/roads` | City Kit (Roads) | ไฟจราจร ป้ายหยุด ป้ายเตือน กรวย แบริเออร์ ถังขยะใหญ่ |
| `props/nature` | Nature Kit | ต้นไม้ พุ่มไม้ ดอกไม้ |
| `props/carkit` | Car Kit | ลังกล่อง / กรวย (ใช้เป็นสิ่งกีดขวางเตี้ย) |

ของที่ยังสร้างจากโค้ดเอง (ไม่ใช่โมเดล Kenney): รถเมล์สาย 8, รถเข็นแม่ค้า, ม้านั่งคนหลับ, แมวจร, คนเดินถนน, ถังขยะ/ถุงขยะ, ก๊อกน้ำดับเพลิง, เสาไฟ, ป้ายร้าน, ไม้กั้นทางข้าม
ถ้าลบไฟล์ในโฟลเดอร์ใด เกมจะกลับไปใช้โมเดลจากโค้ดแทนอัตโนมัติ ถ้าวางไฟล์ `.glb` เพิ่มใน `buildings/` หรือ `vehicles/` (รวมโฟลเดอร์ย่อย) ระบบจะสุ่มใช้ให้เอง
